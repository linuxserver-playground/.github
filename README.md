# .github

The community health files for the `linuxserver-playground` GitHub organisation. GitHub applies
everything here to every repository in the org that does not define its own copy.

| Path | Used for |
| --- | --- |
| `.github/ISSUE_TEMPLATE/` | Bug report and feature request issue forms, and the contact links shown on "New issue". |
| `.github/PULL_REQUEST_TEMPLATE.md` | The pull request template. |
| `CONTRIBUTING.md` | How to contribute to an image repository in the v2 layout. |
| `SECURITY.md` | How to report a vulnerability, and that playground images are unsupported. |
| `FUNDING.yml` | LinuxServer.io sponsorship links. |
| `profile/README.md` | The organisation profile page. |

Image repositories do not carry their own issue templates or contributing guide; change them here.
The contract the files describe is
[`CONVENTIONS.md`](https://github.com/linuxserver-playground/builder/blob/main/CONVENTIONS.md) in the
`builder` repository.
